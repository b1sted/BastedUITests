# Главная страница. Внешние ссылки главного меню

## Детали

### Предварительные условия

1. Тестирование проводится на десктопной версии с разрешением от 1200px и на мобильной в режиме инкогнито.
2. Перейти на страницу `https://basted.ru/`.

### Характеристики

* **Приоритет:** P1
* **Слой тестирования:** UI (Browser)

## Тестовый сценарий

### Тестовая матрица

| № | Проверяемый элемент     | Ожидаемый URL               |
|:-:|:------------------------|:----------------------------|
| 1 | «Проекты»               | Содержит `github.com`       |
| 2 | «Конспекты лекций по C» | Содержит `basted.ru`        |
| 3 | «Поддержать»            | Содержит `pay.cloudtips.ru` |

### Пошаговый сценарий

| № | Шаг                                          | Ожидаемый результат                                                                                                                                                |
|---|----------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Нажать на кнопку из строки матрицы           | Открывается новая вкладка браузера с соответствующей страницей (URL согласно матрице).<br/>Исходная вкладка с Главной страницей остаётся открытой и не изменяется. |
| 2 | Закрыть новую вкладку                        | Фокус возвращается на исходную вкладку с Главной страницей, её состояние не изменилось.                                                                            |
| 3 | Повторить шаги 1-2 для каждой строки матрицы | Все переходы открываются в новых вкладках корректно, исходная вкладка остаётся стабильной.                                                                         |
