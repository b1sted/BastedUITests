# Главная страница. Навигация по разделам с главной страницы

## Детали

### Предварительные условия

1. Тестирование проводится на десктопной версии с разрешением от 1200px и на мобильной в режиме инкогнито.
2. Перейти на страницу `https://basted.ru/`.

### Характеристики

* **Приоритет:** P1
* **Слой тестирования:** UI (Browser)

## Тестовый сценарий

### Тестовая матрица

| № | Проверяемый элемент | Ожидаемый URL |
|:-:|:--------------------|:--------------|
| 1 | «Блог»              | `/blog`       |
| 2 | «Ассемблер»         | `/assembly`   |
| 3 | «Обо мне»           | `/about`      |

### Пошаговый сценарий

| № | Шаг                                          | Ожидаемый результат                                                                       |
|---|----------------------------------------------|-------------------------------------------------------------------------------------------|
| 1 | Нажать на кнопку из строки матрицы           | Открывается соответствующая страница (URL согласно матрице), отображается кнопка «Назад». |
| 2 | Нажать на кнопку «Назад»                     | Возвращение на Главную страницу (URL = `/`).                                              |
| 3 | Повторить шаги 1-2 для каждой строки матрицы | Все переходы и возвраты работают корректно.                                               |
