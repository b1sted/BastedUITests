# Карта сайта. Проверка доступности всех URL из `sitemap.xml`

## Детали

### Предварительные условия

Файл карты сайта доступен по адресу: `https://basted.ru/sitemap.xml`.

### Характеристики

* **Приоритет:** P1
* **Слой тестирования:** API (Headless)

## Тестовый сценарий

### Пошаговый сценарий

| № | Шаг                                                                                | Ожидаемый результат                                                                               |
|---|------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| 1 | Отправить GET запрос к файлу `sitemap.xml` и распарсить его содержимое.            | Запрос успешен (Код 200). Извлечен массив уникальных URL адресов. Массив не пуст.                 |
| 2 | В цикле отправить HTTP-запрос методом `HEAD` на каждый URL из полученного массива. | Для каждого URL сервер возвращает статус-код `200 OK`.                                            |
| 3 | Собрать результаты неуспешных запросов (коды 4xx, 5xx) в отчет.                    | Выведен список "битых" ссылок с указанием их статус-кодов. Если таких нет — тест пройден успешно. |
